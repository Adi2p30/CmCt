# Introduction
This document provides an overview of the theory and methodology behind the calving comparison analysis performed.

The calving module of the CmCt is designed to facilitate the analysis of calving events in ice sheets and glaciers. Fundamentally, it compares obseervation calving data from satellites to models and simulations of calving processes. The module is built on the CmCt framework, which is a comprehensive tool for climate model comparison and analysis.

This module provides tools for data preprocessing, analysis, and visualization.
Specifically it has the following features:
- **Automated Pipeline** 

- **Flexible Data Input**
