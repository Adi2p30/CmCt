# How to Use the Calving Comparison Tool
There are lots of features and different analysis that the calving module provides. 
1. The most important thing that the calving module does it that it is designed to be flexible, different data formats can be used, and different models can be compared.
2. The calving module is designed to be used with the CmCt framework, which provides a comprehensive set of tools for climate model comparison and analysis.
3. The module provides tools for data preprocessing, analysis, visualization and different types of comparisons.
